# 역사의 시선 — 역사 서논술형 평가

산업혁명·제국주의 문항 PDF 두 개를 활용하는 Streamlit 앱입니다. Google Forms와 유사한 입력·최종 제출 방식이며 Google Forms 연동은 하지 않습니다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

처음에는 **미리 체험하기 → 체험 시작**으로 동작을 확인할 수 있습니다. 체험 답안은 DB에 저장하지 않습니다.

## 실제 수업 준비

1. `.streamlit/secrets.example.toml`을 `.streamlit/secrets.toml`로 복사합니다.
2. `python auth.py`를 실행하여 교사와 학생별 비밀번호의 해시를 생성합니다. 평문 비밀번호는 파일에 넣지 않습니다.
3. 교사 해시와 학생 아이디별 이름·해시를 설정합니다. 학생 계정은 교사가 발급하며 공개 회원가입은 없습니다. 학생에게 자신의 계정만 전달하세요.
4. HTTPS를 지원하고 **영구 디스크**가 있는 서버에서 앱을 실행합니다. `ASSESSMENT_DB_PATH`를 영구 볼륨의 SQLite 경로로 지정할 수 있습니다. 기본값은 `runtime/assessment.sqlite3`입니다.

학생은 로그인 후 평가를 선택합니다. **학생 계정당 각 평가 1회** 제출할 수 있습니다. 두 PDF를 각각 하나의 평가로 제공하며 각 평가의 총점은 원본과 동일한 20점입니다. 1번 문항은 명칭을 쓰는 단답형과 생산량을 설명하는 서술형으로 나누되, 점수는 합산 4점입니다. 문항2의 원본 번호 3-1~3-3을 유지했습니다.

모든 문항에 답하고 확인란을 선택해야 최종 제출할 수 있습니다. 제출 후에는 수정할 수 없고 결과만 확인합니다. 단일 SQLite의 복합 기본키가 동시 제출도 차단합니다. 계정 공유·다중 계정 발급을 막는 학교별 관리가 필요하며, DB 삭제·초기화 시 응시 기록도 사라집니다. 여러 앱 인스턴스를 독립 디스크에서 실행하지 마세요. 클라우드의 임시 디스크만 사용하는 배포는 실제 평가에 적합하지 않습니다. 학생 개인정보를 포함한 DB와 CSV는 접근을 제한하고 학교 방침에 따라 보관·삭제하세요.

## 피드백과 채점

- 단답형: 허용된 표기와 비교하여 즉시 정오 판정. 띄어쓰기와 영문 대소문자를 정규화합니다.
- 서술·논술형: 핵심 표현을 확인하는 **규칙 기반 예비 피드백**입니다. AI 의미 분석이나 완전 자동 채점은 구현하지 않았습니다. 키워드만 나열한 글, 부정문, 모순, 다른 정당한 표현은 교사 검토가 필요합니다.
- 교사: 로그인 유형을 교사로 선택하여 제출별 최종 정오·점수·추가 피드백을 저장합니다. 학생은 재로그인하거나 새로고침하면 확인할 수 있습니다. 교사 화면에서만 전체 제출과 CSV 내보내기가 가능합니다.
- 정답 문장이나 모범 답안을 학생에게 보여주지 않고 관련 역사적 사실과 보완 방향을 제공합니다. 교사 추가 피드백도 같은 원칙으로 작성해야 합니다.
- PDF 원본에 포함된 그림·기사·지도를 이미지로 표시하며 답안 PDF는 노출하지 않습니다. 문서 내부 문구는 평가 자료로만 사용합니다.

함께 제공된 `논술형 문항2 답안.pdf` 마지막 기준은 영국의 정책을 ‘횡단정책’으로 표기하고 있어 검토가 필요합니다. 앱은 영국의 종단정책을 기준으로 예비 피드백을 구성하며, 교사 화면에 이를 명시합니다. 원본 파일은 변경하지 않았습니다.

관련 사실 참고: [영국 국립문서보관소의 공장법 자료](https://www.nationalarchives.gov.uk/education/resources/1833-factory-%20act/), [영국 국립육군박물관의 이집트·수단 자료](https://www.nam.ac.uk/explore/egypt-and-sudan).
