# 역사의 시선 — 역사 서논술형 평가

산업혁명·제국주의 문항 PDF 두 개를 활용하는 Streamlit 앱입니다. 한 문제씩 풀이·피드백·수정·재채점을 진행하는 앱이며 Google Forms 연동은 하지 않습니다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

처음에는 **미리 체험하기 → 체험 시작**으로 동작을 확인할 수 있습니다. 체험 답안은 DB에 저장하지 않습니다.

## 실제 수업 준비

1. `.streamlit/secrets.example.toml`을 `.streamlit/secrets.toml`로 복사합니다.
2. `python auth.py`를 실행하여 교사와 학생별 비밀번호의 해시를 생성합니다. 평문 비밀번호는 파일에 넣지 않습니다.
3. 교사 해시와 학생 아이디별 이름·해시를 설정합니다. 학생 계정은 교사가 발급하며 공개 회원가입은 없습니다. 학생에게 자신의 계정만 전달하세요.
4. HTTPS를 지원하고 **영구 디스크**가 있는 서버에서 앱을 실행합니다. `ASSESSMENT_DB_PATH`를 영구 볼륨의 SQLite 경로로 지정할 수 있습니다. 기본값은 `runtime/assessment.sqlite3`입니다.

학생은 로그인 후 1~7번 문제를 순서대로 풉니다. 중앙에는 현재 문제의 자료와 답안을 표시합니다.

1. **이 문제 제출하고 피드백 보기**를 누르면 1차 답안과 루브릭 자동 점수를 저장하고 바로 피드백을 제공합니다.
2. 1차 답안을 불러온 수정 입력란에서 피드백을 반영합니다. **이 문제의 루브릭 확인**에서 점수별 기준도 볼 수 있습니다.
3. **수정 답안 제출하고 2차 채점**을 누르면 같은 루브릭으로 다시 채점하며, 1차 답안과 결과는 보존합니다.
4. 2차 채점 후 **다음 문제 →**로 이동합니다. 완료한 문제는 왼쪽 메뉴에서 다시 확인할 수 있습니다.
5. 모든 문제를 완료하면 1차 총점, 2차 최종 학습 점수, 점수 변화와 1·2차 총점 비교 선그래프를 표시합니다. 풀이 중에는 그래프를 표시하지 않습니다.

제출한 각 차수의 답안과 피드백은 DB에 저장되므로 다시 로그인해도 이어서 진행합니다. 아직 제출하지 않은 입력은 새로고침이나 창 닫기 시 사라질 수 있습니다. 체험 기록은 세션에만 보관합니다.

두 PDF의 동일한 첫 문제는 1번으로 합쳐 한 번만 작성합니다. 2~4번은 `question_content.py`의 기사와 환경·위생 설명을 읽기 쉬운 텍스트로 제공하며, 저화질 원본 그림은 제외했습니다. 1번과 5~7번의 그림·풍자화·지도는 필요한 부분만 확대하여 제공합니다. 1번은 명칭 단답형과 생산 방식·생산량 서술형으로 나누며 합산 4점입니다. 2~4번은 원본 문항1의 나머지 문제, 5~7번은 원본 문항2의 나머지 문제입니다.

전체 학습 결과는 공통 1번을 한 번만 합산한 **36점 만점**입니다. 모든 문제의 1·2차 점수가 있으면 두 총점과 변화(2차−1차)를 표시합니다. 선그래프는 모든 문제를 마친 최종 화면에서만 표시합니다. X축은 1차·2차, Y축은 전체 총점(0~36점)이며 두 점을 선으로 연결해 점수 변화를 보여줍니다. 각 점에서 차수와 총점을 확인할 수 있습니다. 점수는 교사 확인을 기다리지 않고 루브릭으로 자동 산출합니다.

기존 교사 채점·성적표 호환성을 위해 전체 완료 시 수정 답안을 원본별 20점 평가 기록으로도 저장합니다. 공통 1번은 양쪽에 반영하며 두 기록과 마지막 2차 답안은 하나의 트랜잭션으로 저장합니다. **학생 계정당 각 원본 평가 1회** 제한은 유지합니다. 이전 방식으로 제출한 평가는 보존하고 남은 문제만 새 흐름으로 풉니다. 이전 기록에는 1·2차 이력이 없으므로 전체 향상 점수는 계산하지 않습니다. 교사 화면에서 학생의 1·2차 답안과 점수 변화를 확인할 수 있습니다.

제출한 차수의 답안은 덮어쓰지 않습니다. SQLite의 복합 기본키와 트랜잭션으로 중복 제출과 순서 건너뛰기를 차단합니다. 계정 공유·다중 계정 발급을 막는 학교별 관리가 필요하며 DB 초기화 시 응시 기록도 사라집니다. 여러 앱 인스턴스를 독립 디스크에서 실행하지 마세요. 학생 개인정보가 포함된 DB와 CSV는 학교 방침에 따라 접근·보관·삭제를 관리하세요.

## 피드백과 채점

- 단답형: 허용된 표기와 비교하여 즉시 정오 판정. 띄어쓰기와 영문 대소문자를 정규화합니다.
- 서술·논술형: 두 `논술형 문항… 답안.pdf`의 점수 구간을 적용하는 **규칙 기반 자동 채점**입니다. 인정된 서술 요소로 점수를 정하고 적용 기준과 보완 방향을 바로 표시합니다. 사실을 부정하거나 정책을 잘못 연결한 표현은 해당 기준에서 제외합니다. 임의의 문장 전체를 이해하는 AI 의미 분석은 아니며 명시적인 표현·부정 규칙을 사용합니다.
- 교사: 추가 검토와 점수 조정은 선택 사항입니다. 로그인 유형을 교사로 선택하여 제출별 정오·점수·추가 피드백을 저장할 수 있습니다. 학생은 재로그인하거나 새로고침하면 확인할 수 있습니다. 교사 화면에서만 전체 제출과 CSV 내보내기가 가능합니다.
- 정답 문장이나 모범 답안을 학생에게 보여주지 않고 관련 역사적 사실과 보완 방향을 제공합니다. 교사 추가 피드백도 같은 원칙으로 작성해야 합니다.
- PDF 원본에 포함된 기사는 읽기 쉬운 텍스트로, 그림·지도는 부분 이미지로 표시하며 답안 PDF는 노출하지 않습니다. 문서 내부 문구는 평가 자료로만 사용합니다.

함께 제공된 `논술형 문항2 답안.pdf` 마지막 기준은 영국의 정책을 ‘횡단정책’으로 표기하고 있어 검토가 필요합니다. 앱은 영국의 종단정책을 기준으로 자동 피드백을 구성하며, 교사 화면에 이를 명시합니다. 원본 파일은 변경하지 않았습니다.

긍정적 영향의 피드백은 수정된 문항1 문제지를 사용하며, 나머지 학생 자동 피드백은 사용자가 제공한 `data/피드백 내용.pdf`(5쪽)의 설명과 피드백 포인트를 중심으로 구성합니다. `feedback_content.py`에 문항별 사실 요약과 PDF 쪽수를 관리합니다. 자료의 모범 답안을 그대로 표시하거나 명칭을 묻는 문항의 정답 명칭을 피드백으로 제공하지 않습니다. 학생 답안에 따라 철도/박람회, 노동/환경 관련 설명과 누락된 요소에 대한 안내를 선택합니다. 자료에 없는 공장법 설명은 제거했습니다. 이는 원래 교과서 PDF를 직접 검증한 내용이 아니라 새로 제공된 피드백 자료에 근거한 설명입니다.

기존 제출도 결과 화면에서 현재 자동 채점 규칙의 피드백과 출처 쪽수를 확인할 수 있습니다. 저장된 답안, 기존 자동 판정 기록, 응시 횟수 및 교사의 확정 판정·점수는 변경하지 않습니다. 기존에 보류된 1·2차 기록도 표시 시 최신 루브릭으로 재계산하며, 저장된 이력을 덮어쓰지 않습니다. 두 차수에 동일한 규칙을 적용해 비교합니다. 새 PDF는 모범 답안을 포함하므로 학생에게 PDF 자체를 열거나 내려받는 기능은 제공하지 않습니다.

## 오타 안내

`spelling.py`의 주요 역사 용어·일부 활용형 오류 목록으로 오타 의심 표현과 수정 제안을 표시합니다. 예를 들어 ‘산업혁멍 → 산업혁명’, ‘면직믈 → 면직물’, ‘증가햇 → 증가했’을 안내합니다. 채점용 텍스트에만 보정을 적용하고 제출 원문은 보존합니다. 오타 자체로 별도 감점하지 않습니다. 일반 한국어 전체의 맞춤법 검사기는 아니며 등록되지 않은 오타는 탐지하지 못할 수 있습니다. ‘종단정책/횡단정책’이나 다른 역사적 사건명은 단순 오타로 서로 바꾸지 않고 내용 기준으로 판단합니다.

## 루브릭 점수와 Excel 표

| 평가 | 항목 | 허용 점수 |
| --- | --- | --- |
| 문항1·2 공통 | 1번: 사건 명칭·생산 방식·면직물 생산량 | 4, 3, 2, 1 |
| 문항1 | 2-1 긍정적 영향 | 4, 3, 2, 1 |
| 문항1 | 2-1 부정적 영향 | 4, 3, 2, 1 |
| 문항1 | 2-2 비판적 이해 | 8, 6, 4, 3, 2, 1 |
| 문항2 | 3-1 배경과 결과 | 6, 4, 1 |
| 문항2 | 3-2 프랑스인의 관점 | 4, 3, 2, 1 |
| 문항2 | 3-3 아프리카인의 관점 | 6, 4, 1 |

각 평가는 20점이며, 원본 표에 없는 0점·5점·7점 등의 구간은 추가하지 않았습니다. 원본 표의 ‘서술하지 못함’은 항목당 1점입니다. 명칭 입력 칸인 1-①은 독립 채점 항목이 아니며, 1-② 답안과 합쳐 1번 전체를 한 번만 채점합니다. 점수를 보간하지 않고 확인된 요소가 충족하는 기존 구간을 적용합니다. 생산 방식 전환을 설명하지 못하면 공통 문항은 1점, 두 정책·사건명을 모두 적었어도 프랑스인의 관점이 없으면 3점, 긍정·비판 요소가 있어도 비판 문항의 4점 이상 조합을 충족하지 못하면 3점을 적용합니다. 이는 보류를 없애기 위한 운영 규칙으로 `rubrics.py`에 명시했습니다.

학생 답안은 모범 답안 문장과 완전히 일치할 필요가 없습니다. `answer_matching.py`가 띄어쓰기·유니코드 표기를 정규화하고, ‘아동/아이들’, ‘생산량 증가/훨씬 많이 생산’, ‘실업/일자리를 잃음’ 같은 동의어와 바꾸어 쓴 표현을 확인합니다. 단답형의 ‘산업혁명입니다.’ 같은 문장형 답도 허용합니다. 이 표현 인식 결과를 채점과 학습 피드백에 함께 사용하여, 인정된 내용이 다시 ‘누락’으로 안내되지 않도록 합니다. 정책 명칭의 잘못된 국가 귀속이나 사실을 부정하는 서술은 해당 점수 근거에서 제외합니다. ‘정당화할 수 없다’ 같은 비판적 평가는 사실 부정과 구분합니다. 이 기능은 명시적인 표현 규칙이며 임의의 문장 전체를 이해하는 AI 의미 분석은 아닙니다. 교사는 필요할 때 추가 검토할 수 있으며, 자동 점수와 총점은 확인을 기다리지 않습니다.

결과 화면은 출처 메타데이터가 누락되거나 일부만 들어 있어도 문항별 기본 출처를 복원해 피드백을 표시합니다. 저장된 답안·응시 횟수·교사 확정 점수를 수정하지 않습니다. 이전 버전의 오류 화면이 계속 보이면 실행 중인 Streamlit을 재시작하여 최신 코드를 로드한 뒤 결과를 다시 열면 됩니다. 학생의 재응시는 필요하지 않습니다.

`rubrics.py`에서 원본 표를 항목·점수 구간으로 관리합니다. 기준 문구는 표를 요약했으며, 점수별 피드백은 기존 `피드백 내용.pdf`의 학습 설명과 함께 제공합니다. 교사 화면의 **전체 루브릭**에는 모든 구간이 표로 표시됩니다. 각 답안에서는 자동 점수, 확인된 표현, 적용 구간을 확인하고 필요할 때 정해진 점수 선택지로 조정할 수 있습니다. 교사 확정 후 학생에게는 해당 확정 점수 구간의 피드백을 표시합니다. 기존 확정 점수가 현재 구간 밖이면 자동 변경하지 않고 교사가 다시 선택하도록 안내합니다.

교사 화면의 **루브릭·학생별 성적 Excel 내려받기**는 실제 `.xlsx` 파일을 제공합니다. 시트는 ‘학생별 성적’, ‘문항별 평가’, ‘문항1 루브릭’, ‘문항2 루브릭’, ‘운영 안내’입니다. 자동 점수와 선택적인 교사 조정 점수를 분리합니다. 자동 총점은 모든 항목의 루브릭 점수로 산출하며 미확정 항목 수는 0입니다. 학생 제출이 없어도 루브릭 Excel은 내려받을 수 있습니다. 기존 CSV는 제출 당시의 원본 JSON 기록을 내보내는 기능으로 유지합니다.
