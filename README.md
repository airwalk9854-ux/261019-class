# 역사의 시선 — 역사 서논술형 평가

산업혁명·제국주의 문항 PDF 두 개를 활용하는 Streamlit 앱입니다. Google Forms와 유사한 입력·최종 제출 방식이며 Google Forms 연동은 하지 않습니다.

## 실행

```bash
python -m pip install -r requirements.txt
python -m streamlit run streamlit_app.py
```

처음에는 **미리 체험하기 → 체험 시작**으로 동작을 확인할 수 있습니다. 체험 답안은 DB에 저장하지 않습니다.

## 실제 수업 준비

1. `.streamlit/secrets.example.toml`을 `.streamlit/secrets.toml`로 복사합니다.
2. `python auth.py`를 실행하여 교사와 학생별 비밀번호의 해시를 생성합니다. 평문 비밀번호는 파일에 넣지 않습니다.
3. 교사 해시와 학생 아이디별 이름·해시를 설정합니다. 학생 계정은 교사가 발급하며 공개 회원가입은 없습니다. 학생에게 자신의 계정만 전달하세요.
4. HTTPS를 지원하고 **영구 디스크**가 있는 서버에서 앱을 실행합니다. `ASSESSMENT_DB_PATH`를 영구 볼륨의 SQLite 경로로 지정할 수 있습니다. 기본값은 `runtime/assessment.sqlite3`입니다.

학생은 로그인 후 평가를 선택합니다. **학생 계정당 각 평가 1회** 제출할 수 있습니다. 두 PDF를 각각 하나의 평가로 제공하며 각 평가의 총점은 원본과 동일한 20점입니다. 1번 문항은 명칭을 쓰는 단답형과 생산량을 설명하는 서술형으로 나누되, 점수는 합산 4점입니다. 문항2의 원본 번호 3-1~3-3을 유지했습니다.

모든 문항에 답하고 확인란을 선택해야 최종 제출할 수 있습니다. 제출 후에는 수정할 수 없고 결과만 확인합니다. 단일 SQLite의 복합 기본키가 동시 제출도 차단합니다. 계정 공유·다중 계정 발급을 막는 학교별 관리가 필요하며, DB 삭제·초기화 시 응시 기록도 사라집니다. 여러 앱 인스턴스를 독립 디스크에서 실행하지 마세요. 클라우드의 임시 디스크만 사용하는 배포는 실제 평가에 적합하지 않습니다. 학생 개인정보를 포함한 DB와 CSV는 접근을 제한하고 학교 방침에 따라 보관·삭제하세요.

## 피드백과 채점

- 단답형: 허용된 표기와 비교하여 즉시 정오 판정. 띄어쓰기와 영문 대소문자를 정규화합니다.
- 서술·논술형: 두 `논술형 문항… 답안.pdf`의 루브릭 구간을 적용하는 **규칙 기반 예비 채점**입니다. 점수와 점수별 피드백을 즉시 보여주며, 문맥이 모호하거나 명확한 구간이 없으면 점수를 보류합니다. AI 의미 분석은 구현하지 않았으므로 키워드만 나열한 글, 모순, 다른 정당한 표현은 교사가 반드시 확인해야 합니다.
- 교사: 로그인 유형을 교사로 선택하여 제출별 최종 정오·점수·추가 피드백을 저장합니다. 학생은 재로그인하거나 새로고침하면 확인할 수 있습니다. 교사 화면에서만 전체 제출과 CSV 내보내기가 가능합니다.
- 정답 문장이나 모범 답안을 학생에게 보여주지 않고 관련 역사적 사실과 보완 방향을 제공합니다. 교사 추가 피드백도 같은 원칙으로 작성해야 합니다.
- PDF 원본에 포함된 그림·기사·지도를 이미지로 표시하며 답안 PDF는 노출하지 않습니다. 문서 내부 문구는 평가 자료로만 사용합니다.

함께 제공된 `논술형 문항2 답안.pdf` 마지막 기준은 영국의 정책을 ‘횡단정책’으로 표기하고 있어 검토가 필요합니다. 앱은 영국의 종단정책을 기준으로 예비 피드백을 구성하며, 교사 화면에 이를 명시합니다. 원본 파일은 변경하지 않았습니다.

학생 자동 피드백은 사용자가 제공한 `data/피드백 내용.pdf`(5쪽)의 설명과 피드백 포인트를 중심으로 구성합니다. `feedback_content.py`에 문항별 사실 요약과 PDF 쪽수를 관리합니다. 자료의 모범 답안을 그대로 표시하거나 명칭을 묻는 문항의 정답 명칭을 피드백으로 제공하지 않습니다. 학생 답안에 따라 철도/박람회, 노동/환경 관련 설명과 누락된 요소에 대한 안내를 선택합니다. 자료에 없는 공장법 설명은 제거했습니다. 이는 원래 교과서 PDF를 직접 검증한 내용이 아니라 새로 제공된 피드백 자료에 근거한 설명입니다.

기존 제출도 결과 화면에서 새 자료 기준의 예비 피드백과 출처 쪽수를 확인할 수 있습니다. 저장된 답안, 기존 자동 판정 기록, 응시 횟수 및 교사의 확정 판정·점수는 변경하지 않습니다. 예비 판정은 최신 규칙으로 표시되며 최종 채점은 계속 교사가 담당합니다. 새 PDF는 모범 답안을 포함하므로 학생에게 PDF 자체를 열거나 내려받는 기능은 제공하지 않습니다.

## 루브릭 점수와 Excel 표

| 평가 | 항목 | 허용 점수 |
| --- | --- | --- |
| 문항1·2 공통 | 1번: 사건 명칭·생산 방식·면직물 생산량 | 4, 3, 2, 1 |
| 문항1 | 2-1 긍정적 영향 | 4, 3, 2, 1 |
| 문항1 | 2-1 부정적 영향 | 4, 3, 2, 1 |
| 문항1 | 2-2 비판적 이해 | 8, 6, 4, 3, 2, 1 |
| 문항2 | 3-1 배경과 결과 | 6, 4, 1 |
| 문항2 | 3-2 프랑스인의 관점 | 4, 3, 2, 1 |
| 문항2 | 3-3 아프리카인의 관점 | 6, 4, 1 |

각 평가는 20점이며, 원본 표에 없는 0점·5점·7점 등의 구간은 추가하지 않았습니다. 원본 표의 ‘서술하지 못함’은 항목당 1점입니다. 명칭 입력 칸인 1-①은 독립 채점 항목이 아니며, 1-② 답안과 합쳐 1번 전체를 한 번만 채점합니다. 원본 기준이 직접 규정하지 않은 조합은 임의로 점수를 보간하지 않고 교사 검토로 보류합니다.

`rubrics.py`에서 원본 표를 항목·점수 구간으로 관리합니다. 기준 문구는 표를 요약했으며, 점수별 피드백은 기존 `피드백 내용.pdf`의 학습 설명과 함께 제공합니다. 교사 화면의 **전체 루브릭**에는 모든 구간이 표로 표시됩니다. 각 답안에서는 예비 점수, 확인된 표현, 적용 구간을 확인하고 정해진 점수 선택지로 확정합니다. 교사 확정 후 학생에게는 해당 확정 점수 구간의 피드백을 표시합니다. 기존 확정 점수가 현재 구간 밖이면 자동 변경하지 않고 교사가 다시 선택하도록 안내합니다.

교사 화면의 **루브릭·학생별 성적 Excel 내려받기**는 실제 `.xlsx` 파일을 제공합니다. 시트는 ‘학생별 성적’, ‘문항별 평가’, ‘문항1 루브릭’, ‘문항2 루브릭’, ‘운영 안내’입니다. 예비 점수와 교사 확정 점수를 분리하며, 보류된 예비 항목이 있으면 예비 총점도 공란으로 둡니다. 이때 미확정 항목 수를 함께 표시합니다. 학생 제출이 없어도 루브릭 Excel은 내려받을 수 있습니다. 기존 CSV는 제출 당시의 원본 JSON 기록을 내보내는 기능으로 유지합니다.
